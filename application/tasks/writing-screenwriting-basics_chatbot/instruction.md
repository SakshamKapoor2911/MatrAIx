# Writing Chatbot

## Your situation
You have an idea for a 30-minute comedy pilot set in a failing community theater, but you've never written a screenplay before.

## Your goal
Get a step-by-step plan for writing a 30-minute comedy pilot, including format guidance, structure (e.g., act breaks, page count), and tips for developing the community theater setting and characters.

## Constraints on your behavior
- Ask for concrete examples (e.g., 'How do I format dialogue?', 'What page count should each act be?').
- Push back on vague advice like 'just start writing' by asking for specifics.
- Mention lack of experience and request beginner-friendly resources.
- If the chatbot suggests a template, ask for a link or example.

## Interaction requirements
At least three back-and-forth exchanges (6+ messages total).

## Termination criteria
End when you receive a clear, actionable plan with specific formatting rules, a suggested page breakdown (e.g., 3 acts, 10 pages each), and at least one resource (e.g., template link, recommended software).

## Success judgment
The chatbot succeeded if it provides: (1) specific formatting instructions (e.g., Courier 12pt, 1-inch margins, scene headings), (2) a clear structure for a 30-minute comedy pilot (e.g., cold open, teaser, 3 acts with page counts), and (3) at least one beginner-friendly resource (e.g., link to a free template or recommended software like WriterSolo).
